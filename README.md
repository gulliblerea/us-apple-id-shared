## ⚠️ 美区共享号使用铁律

**① 只登 App Store，不登 iCloud**
App Store → 右上角头像 → 拉到底 → 退出登录 → 输入共享美区账号。
不要在「设置」顶部登录，那是 iCloud 入口，会带来激活锁风险。

**② 弹「升级账户安全」选「不升级」**
选「其他选项」→「不升级」。开了双重认证，别人就都用不了了。

**③ 下载完立刻退出**
不退出会导致账号被锁，锁了之后下一个用的人就用不了——这是共享号最常见的死法。
